# SIGINT OPS dashboard

A responsive, dependency-free HTML and CSS intelligence operations dashboard.

## Run locally

Open `index.html` in a browser. The dashboard includes an animated radar, signal
and priority totals, mission progress cards, threat status, quick-action buttons,
and a responsive bottom navigation bar.

## Project files

- `index.html` contains the dashboard structure and report content.
- `styles.css` contains the dark theme, responsive layout, and animations.
- `script.js` handles dashboard action feedback and navigation selection.
