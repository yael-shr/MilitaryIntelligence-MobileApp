# SIGINT OPS Dashboard

A dark-themed, single-page intelligence operations dashboard built with plain HTML and CSS. The interface presents a tactical overview of active signals, mission priorities, operational status, and quick-access controls in a compact mobile-first layout.

## Overview

This project simulates a military-style command dashboard for monitoring intelligence activity. It includes:

- Animated radar display with scanning motion
- Mission cards with priority levels and progress bars
- Signal and alert summary counters
- Threat detection banner
- Action buttons for quick operational tasks
- Responsive bottom navigation for dashboard-style mobile layouts

## Project structure

- `index.html` — dashboard layout and content
- `styles.css` — visual design, dark theme, animations, layout, and responsive styling
- `LICENSE` — project license

## Run locally

This is a static HTML/CSS project, so no installation or build step is required.

1. Open the project folder.
2. Double-click `index.html` in your file explorer, or open it directly in a browser.
3. The dashboard will load immediately.

If you prefer to serve it locally with a web server, you can use any static server tool, but it is not required for this project.
## Design notes

The dashboard uses a cyber-intelligence aesthetic with:

- green accent styling and dark panels
- glass-like overlays and subtle grid textures
- animated operational indicators
- compact status labels for mission tracking
